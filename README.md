# Zomato Data Analysis Project

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Zomato dataset to understand customer behavior, restaurant trends, ratings, votes, and spending patterns.

The goal of this project is to extract meaningful business insights using Python and data visualization techniques.

---

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn

---

## 📊 Business Questions Solved

1. Which type of restaurant do the majority of customers order from?
2. How many votes has each type of restaurant received from customers?
3. What are the ratings that the majority of restaurants have received?
4. What is the average spending of couples ordering food online?
5. Which mode (Online/Offline) has received maximum ratings?
6. Which type of restaurant received more offline orders?

---

## 📈 Key Insights
- Majority of customers prefer Dining restaurants.
- Dining restaurants received the highest number of votes.
- Most restaurants have ratings between 3.5 and 4.0.
- Average spending for two people is around ₹400–₹500.
- Online orders received higher ratings compared to offline orders.
- Dining restaurants received the highest number of offline orders.
